# Cross-Repo Knowledge Base

This is the **compounded, curated knowledge** distilled from all Manfred repos. It is
distinct from a project's own `knowledge/` directory, which is the per-project flywheel
(local errors, local decisions). This base grows by **graduation**: when a per-project
truth proves to recur across multiple projects, it moves up here.

## Category files

| File | What it covers |
| --- | --- |
| [gotchas.md](gotchas.md) | Recurring traps — symptoms, causes, fixes |
| [domain.md](domain.md) | Product/brand/design-system context shared across all repos |
| [procedural.md](procedural.md) | Cross-repo how-tos: deploy, Linear, ratchets, releases |

## Maintenance

Review periodically; merge overlapping entries; split files that grow too long; remove
stale entries when the underlying tool or process changes.
